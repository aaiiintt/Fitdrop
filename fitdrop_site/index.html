The Tech Stack:

  • Gemini 1.5 Pro: Vibe coding & logic.
  • Nano Banana: Image synthesis.
  • Matter.js: 2D Physics engine.
  • Python: Asset pipeline.

Built rapidly as a "vibe coding" experiment to test the speed of AI-assisted prototyping.

The Experiment:

Two questions driving this project:

  1. Can AI accurately recreate specific fashion aesthetics from the last 45 years?
  2. How fast can we go from "idea" to "deployed interactive web app" using modern AI tools?

(And yes, dropping things is just satisfying.)
